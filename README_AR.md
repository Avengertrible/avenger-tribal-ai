# المشروع

هذا مشروع Python بسيط قابل للنشر على Render.

## الملفات

- `app.py` — نقطة تشغيل تطبيق Flask.
- `engine.py` — منطق المحرك الأساسي.
- `requirements.txt` — المكتبات المطلوبة.
- `render.yaml` — إعدادات النشر على Render.

## التشغيل محليًا

```bash
pip install -r requirements.txt
python app.py
```

ثم افتح:
`http://127.0.0.1:5000`

## النشر

ارفع الملفات إلى مستودع GitHub ثم اربط المستودع بخدمة Web Service على Render.
